# 角色设计计划：熊孩子

- 索引：151
- 阵营：townsfolk / good
- 时机：every_night
- 频率：always
- 目标：1 个角色
- 夜序分类：interference
- 规则文本：每个夜晚，你要选择一个镇民角色：他的能力会产生错误信息，直到下个黄昏。
- 角色介绍：熊孩子会指定一个镇民角色，让该角色对应的玩家直到下个黄昏前都只能产生错误信息。

## 效果
- 自定义效果 choose_townsfolk_role_for_wrong_info：选择的是镇民角色而不是玩家；只影响真实拥有该角色的玩家，不影响仅借用该能力的玩家。角色后来进场时仍会获得捣蛋效果。

## Token
- 捣蛋（熊孩子）（捣蛋 / rascal_prank）：该角色通过自身能力获得的信息必定错误。；图标：botc_tk151.dds；放置：熊孩子清醒健康地选择该镇民角色后。；移除：下个黄昏、熊孩子死亡或离场。；可见性：storyteller

## 相克规则
- 涡流：双方各自使用独立的捣蛋与信息错误标记，不互相覆盖。
