# 角色设计计划：书生

- 索引：152
- 阵营：outsider / good
- 时机：passive
- 频率：once_per_game
- 目标：无目标
- 夜序分类：kill
- 规则文本：恶魔知道书生在场。每局游戏限一次，恶魔可以拜访说书人并猜测你是书生。如果恶魔猜测正确，即使你已死亡，当晚该恶魔可以选择一名玩家：他死亡。
- 角色介绍：恶魔通过「声称/猜测」猜测书生。正确猜测产生可行动标记，错误猜测只记录已猜测；多名书生能力者分别记录。

## 效果
- 自定义效果 manual_guessed_token_extra_kill：按来源座位记录 token 171。只有正确猜测产生的可行动标记会打开单目标刀人面板；行动后或来源能力者中毒、醉酒时移回来源，死亡记录为 172。能力者死亡后仍保留能力和已猜测标记，恶魔仍可猜测他；多名能力者的标记在换身份或离场时独立清理。所有真恶魔与所有书生共享一次真实猜测机会，未获告知的恶魔不能消耗，中毒或醉酒的恶魔提交后仍会消耗。执行者仍为真恶魔时先结算恶魔负面能力保护与免疫；最终死亡始终是非恶魔攻击，不触发亡骨魔保留能力或守鸦人、贤者、报丧女妖。

## Token
- 已猜测（书生）（已猜测 / pedant_guessed）：正确猜测时放在恶魔身上并赋予一次夜间额外行动；行动后或对应书生失能时移回该能力者。错误猜测只放在书生能力者身上，不赋予行动。；图标：botc_tk152.dds；放置：已得知书生在场的真恶魔使用猜书生且本局共享机会尚未消耗时。全部猜错则所有能力者各放一枚；猜中其一时恶魔与未猜中的其他能力者分别放置。共享机会由独立持久状态记录，不以 token 是否仍存在为准。；移除：游戏结束时，或对应书生能力者换身份、离场时；只清除该来源的标记。死亡不会移除标记。；可见性：storyteller
- 死亡（书生）（书生死亡 / pedant_death）：记录由书生能力造成的额外死亡。；图标：botc_tk152.dds；放置：带已猜测 token 的玩家完成书生刀人后。；移除：按普通死亡 token 规则在复活或新局时移除。；可见性：storyteller

## 规则测试
- [ ] 首夜在书生顺位告知所有恶魔书生在场
- [ ] 首夜不唤醒书生本人
- [ ] 未获告知的真恶魔不能消耗猜测机会，也不会收到差异化目标反馈
- [ ] 中毒或醉酒的真恶魔提交猜测后仍消耗共享机会
- [ ] 已猜测 token 被清理、换夜或来源离场后共享机会仍不恢复
- [ ] 其他恶魔后续提交不触发效果，也不会收到机会是否耗用的反馈
- [ ] 单书生猜错时标记放在能力者身上且不产生夜间行动
- [ ] 单书生猜对时标记放在恶魔身上并提供一次单目标刀人
- [ ] 多书生全部猜错时所有能力者同时放置标记
- [ ] 多书生猜中其一时恶魔与未猜中的能力者分别放置标记
- [ ] 刀人后或来源能力者中毒、醉酒时将标记移回该能力者
- [ ] 刀人结算记为死亡（书生），不是恶魔攻击
- [ ] 真恶魔执行时士兵、僧侣和魔鬼代言人保护生效，非恶魔执行时不按恶魔负面能力处理
- [ ] 死亡不触发亡骨魔保留被杀爪牙能力，也不触发守鸦人、贤者、报丧女妖
- [ ] 同一夜晚不会重复触发，黎明不清除已猜测 token
- [ ] 能力者死亡后已猜测 token 与能力保留，恶魔仍能猜测他并触发对应额外行动
- [ ] 一名能力者换身份或离场时只清除其来源标记，不影响其他能力者
- [ ] 游戏结束或开始新一局时清除已猜测 token 和行动状态
- [ ] 书生不进入全员追忆角色池
