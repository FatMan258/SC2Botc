# 角色设计计划：书生

- 索引：152
- 阵营：outsider / good
- 时机：passive
- 频率：once_per_game
- 目标：无目标
- 夜序分类：kill
- 规则文本：恶魔知道书生在场。每局游戏限一次，恶魔可以拜访说书人并猜测你是书生。如果恶魔猜测正确，即使你已死亡，当晚该恶魔可以选择一名玩家：他死亡。
- 角色介绍：本图由说书人手动处理拜访与猜测。正确的恶魔由说书人放置「已猜测」token，并在书生夜序获得一次额外攻击。

## 效果
- 自定义效果 manual_guessed_token_extra_kill：说书人负责恶魔拜访和猜测。只有带 171 token 的玩家在书生夜序打开单目标刀人面板；死亡记录为 172。

## Token
- 已猜测（书生）（已猜测 / pedant_guessed）：该玩家可在今晚书生夜序额外选择一名玩家死亡。；图标：botc_tk152.dds；放置：说书人手动确认恶魔正确猜测书生后。；移除：点击进入白天时，或开始新一局时。；可见性：storyteller
- 死亡（书生）（书生死亡 / pedant_death）：记录由书生能力造成的额外死亡。；图标：botc_tk152.dds；放置：带已猜测 token 的玩家完成书生刀人后。；移除：按普通死亡 token 规则在复活或新局时移除。；可见性：storyteller
