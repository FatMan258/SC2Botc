# 角色设计计划：食人魔

- 索引：148
- 阵营：outsider / good
- 时机：first_night
- 频率：once_per_game
- 目标：1 名玩家，不能选择自己
- 夜序分类：role_change
- 规则文本：在你的首个夜晚，你要选择除你以外的一名玩家：你转变为他的阵营，即使你已醉酒或中毒，但你不知道你转变后的阵营。
- 角色介绍：食人魔把一名玩家当作挚友，并立即加入挚友当时的阵营。无论朋友之后走向哪里，食人魔都不会自动跟随，也不会主动得知自己最终站在哪一边。
- 规则来源：https://clocktower-wiki.gstonegames.com/index.php?title=%E9%A3%9F%E4%BA%BA%E9%AD%94

## 效果
- 自定义效果 set_alignment_from_target：选择后立即按目标当时的登记阵营设置善良或邪恶。该能力即使食人魔醉酒或中毒也生效；通常不告知食人魔最终阵营。

## Token
- 无 token

## 相克规则
- 陌客：如果陌客被食人魔当作邪恶阵营，食人魔会得知自己转变为邪恶。
- 间谍：间谍必定被食人魔当作邪恶阵营。
- 麻脸巫婆：被麻脸巫婆创造的邪恶食人魔，无法因为自身能力转变为善良阵营。
- 科学怪人：恶魔无法拥有食人魔的能力。

## 实现说明
- 选择后立即按目标当时的客观登记阵营，为食人魔写入善良或邪恶 token。
- 食人魔自身中毒或醉酒时能力仍完整生效，不叠加观察者“看错阵营”滤镜。
- 间谍对食人魔强制登记为邪恶；陌客登记为邪恶时，额外私聊食人魔得知自己变为邪恶。
- 麻脸巫婆创造的邪恶食人魔保留邪恶；科学怪人及其嵌套哲学家都不能把该能力交给恶魔。
- 15 人以上可选“挚友”规则不启用，本图最多 12 名玩家。
- 图标原图保存在 `assets/source/role_148_ogre.png`，DDS 运行素材由
  `assets/game/` 自动注入地图并随仓库提交。
