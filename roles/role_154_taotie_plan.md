# 角色设计计划：饕餮

> DSL 的 `target_count=1` 只用于表示“存在主动选目标能力”，也是运行时启用技能按钮的哨兵值。
> 饕餮实际直接在圆桌上点击选择 0..12 名玩家；不得改回十二行长按钮或普通三目标面板。

- 索引：154
- 阵营：demon / evil
- 时机：other_nights
- 频率：always
- 目标：1 名玩家，不能连续重复
- 夜序分类：kill
- 规则文本：每个夜晚*，你要选择任意数量的非旅行者玩家或一名旅行者玩家：如果他们的角色类型均不相同，他们死亡。[+1外来者]
- 角色介绍：饕餮会在夜里选中任意数量的玩家；只要其中出现两种相同的角色类型，它就什么也吃不到。

## 效果
- 自定义效果 setup_plus_one_outsider：饕餮在场时，设置阶段将一名镇民替换为一名外来者。
- 自定义效果 distinct_role_types_only：可选择零到十二名玩家；只有所有目标的真实角色类型均不相同，才按选择顺序结算死亡。目标类型有重复时无人死亡。

## Token
- 死亡（饕餮）（饕餮死亡 / taotie_death）：记录由饕餮能力造成的夜间恶魔死亡，并作为天亮时结算该玩家死亡的依据。；图标：botc_tk154.dds；放置：饕餮确认目标且所选目标的角色类型均不相同后，对可以死亡的每名目标放置。；移除：天亮公开死亡后可由说书人移除；复活或新局时清除。；可见性：storyteller
