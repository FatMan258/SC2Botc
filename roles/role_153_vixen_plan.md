# 角色设计计划：狐媚娘

- 索引：153
- 阵营：minion / evil
- 时机：first_night
- 频率：once_per_game
- 目标：1 名玩家，不能连续重复
- 夜序分类：role_change
- 规则文本：在你的首个夜晚，你要选择一名玩家：他会知道狐媚娘在场。如果你死于处决，当晚他转变为邪恶阵营。
- 角色介绍：狐媚娘先选一名玩家暴露自身，再以自己的处决死亡为代价，让那名玩家在当夜堕入邪恶。

## 效果
- 自定义效果 chosen_player_knows_vixen：首夜选择后，能力正常时受选者立即得知狐媚娘在场；选人时能力失效则恢复后自动补发。
- 自定义效果 execution_turns_chosen_evil：狐媚娘因处决死亡后，在下一夜她的触发位让仍为善良的受选者转为邪恶。

## Token
- 被魅惑（狐媚娘）（被魅惑 / vixen_charmed）：记录狐媚娘首夜选择的玩家，并提示受选者已经得知狐媚娘在场。；图标：botc_tk153.dds；放置：狐媚娘首夜选择玩家后。；移除：狐媚娘因处决死亡后的下一夜处理完毕，或狐媚娘以其他方式死亡 / 离场。；可见性：storyteller
- 被魅惑·未生效（狐媚娘）（被魅惑× / vixen_charmed_invalid）：表示狐媚娘已经完成选择，但受选者尚未得知狐媚娘在场。；图标：botc_tk153.dds；放置：狐媚娘选择时中毒、醉酒或失去能力。；移除：狐媚娘恢复能力并完成告知后换成正常被魅惑标记；其余移除时机同正常标记。；可见性：storyteller

## 相克规则
- 异端分子：互为克星的角色在同一时间里只能有其中一个在场。
- 瘟疫医生：如果说书人本应获得狐媚娘能力，改为一名爪牙获得，且他会得知此事。
