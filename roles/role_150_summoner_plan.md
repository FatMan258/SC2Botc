# 角色设计计划：召唤师

- 索引：150
- 阵营：minion / evil
- 时机：every_night
- 频率：once_per_game
- 目标：1 名玩家和 1 个角色
- 夜序分类：role_change
- 规则文本：在首个夜晚，你会得知三个伪装。在第三个夜晚，你要选择一名玩家：他变成由你选择的邪恶恶魔。[无恶魔在场]
- 角色介绍：召唤师在开局时占用恶魔的位置，但场上没有恶魔；第三个夜晚他会创造一只新的恶魔。

## 效果
- 自定义效果 replace_initial_demon_with_townsfolk：召唤师在场时移除初始恶魔，并用一名不在场的镇民替换；不是把恶魔转成爪牙。
- 自定义效果 third_night_create_demon：第三夜选择一名玩家和一个恶魔角色；目标变为邪恶恶魔并在当晚行动。
- 新增胜利条件（manual_only）

## Token
- 无 token

## 相克规则
- 炼金术士：获得召唤师能力的炼金术士不会获得伪装；他选择恶魔角色，由说书人决定哪名玩家转化。
- 钟表匠：召唤师会被钟表匠当作恶魔。
- 罂粟种植者：罂粟种植者在第三夜存活时，召唤师选择恶魔角色，由说书人决定目标玩家。
- 侍臣：存活的召唤师失去能力时，说书人获得召唤师能力。
- 传教士：存活的召唤师失去能力时，说书人获得召唤师能力。
- 工程师：召唤师离场时，说书人获得召唤师能力。
- 帽匠：如果召唤师创造了第二名存活的恶魔，当晚死亡由说书人决定。
- 麻脸巫婆：如果召唤师创造了第二名存活的恶魔，当晚死亡由说书人决定。
- 卡扎力：如果召唤师创造了第二名存活的恶魔，当晚死亡由说书人决定。
- 提线木偶：提线木偶应在恶魔之后进场，并与恶魔相邻。
- 僵怖：召唤师把已死亡玩家变成僵怖时，该玩家视为已经死过一次。
- 普卡：召唤师可以在第二个夜晚召唤普卡，替代第三个夜晚的召唤。
- 军团：召唤师召唤军团时，所有邪恶玩家会变成军团。
- 堤丰之首：召唤堤丰之首时，他必须与爪牙邻座，另一侧玩家变成邪恶爪牙。

## 规则测试
- [ ] 召唤师在场时初始恶魔被替换为一名镇民，且没有把恶魔转成爪牙
- [ ] 前两夜没有存活恶魔时不会自动判定善良胜利
- [ ] 第三个夜晚可选择任意玩家，包括自己和死亡玩家
- [ ] 第二个夜晚自动进入召唤师行动，角色网格只提供普卡
- [ ] 第二个夜晚选择不发动后，保留第三个夜晚的正常召唤机会
- [ ] 第二个夜晚召唤普卡后，第三个夜晚不会再次召唤
- [ ] 角色网格只列出有效恶魔角色，创建后目标变为邪恶
- [ ] 新恶魔在召唤当晚按恶魔夜序行动
- [ ] 选择已死亡玩家变成僵怖时，保留假死外观，内部视为存活并消耗首次假死
- [ ] 召唤师在成功召唤前死亡时不会自动判胜
- [ ] 第三夜召唤师中毒或醉酒时不会自动判胜
- [ ] 成功召唤后没有恶魔时按正常无恶魔规则判善良胜
- [ ] 新恶魔不自动获得爪牙身份信息

## 警告
- 胜利条件效果必须经过人工审核，并补相克与加时规则
- 存在 custom 效果，不能自动视为完成
