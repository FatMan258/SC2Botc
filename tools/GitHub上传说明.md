# 一键上传 GitHub

双击项目根目录的 `一键上传到GitHub.cmd`。

工具会：

1. 显示当前分支和待上传文件。
2. 要求输入提交说明。
3. 暂存修改。
4. 阻止上传地图、Bank、`work/`、本地素材、环境变量和本机配置。
5. 检查两份 Galaxy 脚本。
6. 运行全部单元测试。
7. 创建 Git 提交并推送当前分支。

新分支第一次上传时，会自动设置 `origin` 上游。

## 不会自动处理的情况

- 本地修改与远程修改冲突。
- GitHub 登录失效。
- 未配置 Git 用户名或邮箱。
- 分支需要先 rebase 或合并。

这些情况会停止上传，不会强制覆盖远程仓库。
