# 一键同步并构建

项目根目录提供两个双击入口：

- `一键同步并构建测试版.cmd`
- `一键同步并构建正式版.cmd`

脚本会依次执行：

1. 检查本地 Git 是否有未提交修改。
2. 切换到 `main`。
3. 从 GitHub 拉取最新代码。
4. 检查地图、脚本、StormLib 和 SC2 环境。
5. 运行 Galaxy 检查和 Python 测试。
6. 构建带时间戳的地图到星际 II 测试地图目录。
7. 回读地图包并打开输出目录。

同一类型只保留最近两张同步地图，避免长期占满 C 盘。正在被游戏占用的旧地图不会被强制删除。

## 本机修改保护

只要 `git status` 发现未提交文件，脚本就会停止。这是为了防止线上更新覆盖正在修改的角色。

先把修改提交到功能分支，再切回 `main` 使用一键同步。

## 自定义输出目录

默认输出：

```text
Documents\StarCraft II\Maps\Test
```

可以设置环境变量覆盖：

```powershell
$env:BOTC_SYNC_OUTPUT_DIR = "E:\StarCraft II\Maps\Test"
```
